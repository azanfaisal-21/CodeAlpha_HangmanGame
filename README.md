# 📖 Description

This is a console-based Hangman Game developed using Python.

The player guesses one letter at a time until the hidden word is completed or all chances are exhausted.

---

# ✨ Features

- Random Word Selection
- Maximum 6 Wrong Attempts
- Duplicate Guess Detection
- Input Validation
- Win / Lose Message
- Console User Interface

---

# 🛠 Technologies Used

- Python
- Random Module
